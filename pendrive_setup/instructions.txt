PORTABLE AI PEN DRIVE SETUP
===========================

To use this folder on your pen drive, you need 3 things in this folder:

1. Start_AI.bat
   This is the file you click to start your AI. It is already included in this folder.

2. The Engine (llama-cli.exe)
   You need the executable that runs the model.
   Download it from: https://github.com/ggerganov/llama.cpp/releases
   (Download the file that looks like 'llama-bXXXX-bin-win-avx2-x64.zip' or similar, extract it, and place 'llama-cli.exe' into this folder).
   Alternatively, you can just run the included 'download_llama.ps1' script to automatically download it for you. (Right-click it and select "Run with PowerShell").

3. The Model (brainmodel.gguf)
   You need the actual AI model file. Place your .gguf file into this folder and ensure it is named exactly 'brainmodel.gguf'.
   IMPORTANT: Make sure the file name exactly matches the one in 'Start_AI.bat'. You can right-click 'Start_AI.bat', select 'Edit', and change 'brainmodel.gguf' to your actual file's name if you decide to change it.

Once you have these 3 files together in this folder, you can copy the whole folder to your pen drive. Plug it into any Windows computer, double click 'Start_AI.bat', and chat offline!
